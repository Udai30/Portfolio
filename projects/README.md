# Project sandboxes
 
Drop a web build of each project into its own folder here, e.g.:
 
- projects/pyxel-runner/index.html  (pygbag/wasm build of the Pygame game)
- projects/football-ml/index.html   (exported demo or visualization)
Then in projects.js set that project's `demo` field to the folder path
(or to an external URL such as a Power BI 'Publish to web' link or a hosted Streamlit app).
